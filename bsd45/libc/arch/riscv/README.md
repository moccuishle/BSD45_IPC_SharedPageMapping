# `libc/arch/riscv`

## English

This directory contains a placeholder platform directory; add its assembly here when that architecture becomes a build target. `config.mk` lists the assembly objects that the
build links for this architecture; C sources contain no inline assembly.

## 中文

本目录包含占位平台目录；该架构成为构建目标时再放入对应汇编。`config.mk` 列出该架构需要编译链接的汇编对象；C 源文件中
不允许出现内联汇编。
